## PhaseFit 是什么？

PhaseFit 是一款基于阶段管理的体重管控应用，通过 AI 辅助追踪营养和运动。不需要手动计算卡路里 -- 拍张照就能获得即时的营养分析，或者用自然语言描述你的运动内容。

### 核心功能

| 功能 | Free | Pro |
|---|---|---|
| 每日 AI 提问次数 | 5 | 30 |
| 食物拍照识别 | 支持 | 支持（高级模型，识别更精准） |
| 营养分析 | 基础 | 完整 |
| 饮食与运动记录 | 支持 | 支持 |
| AI 识别更懂本地饮食 | 支持 | 支持 |
| 快速复制餐食与运动 | 支持 | 支持 |
| 健康体重区间 | 支持 | 支持 |
| AI 模型套餐自选 | -- | GLM5.2 Mix / DeepSeek V4 Pro Mix |
| 每周营养报告与洞察 | -- | 支持 |
| 优先技术支持 | -- | 支持 |

新用户享 **14 天免费试用** Pro 功能，无需绑定信用卡。

### 技术栈

- **前端**：Vue 3 + Vite + TailwindCSS + ECharts
- **后端**：FastAPI + SQLAlchemy (async) + PostgreSQL
- **AI**：多渠道 OpenAI 兼容 API
- **支付**：Creem（Visa、Mastercard、PayPal、Apple Pay、Google Pay）
