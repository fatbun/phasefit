## What is PhaseFit?

PhaseFit is a phase-based weight management app that helps you track nutrition and exercise with AI assistance. Instead of manual calorie counting, you can photograph your meals for instant nutritional analysis or describe your workouts in natural language.

### Core features

| Category | Free | Pro |
|---|---|---|
| AI queries per day | 5 | 30 |
| Food photo recognition | Yes | Yes (advanced models, higher accuracy) |
| Nutritional analysis | Basic | Full |
| Meal & exercise logging | Yes | Yes |
| AI fine-tuned for local cuisines | Yes | Yes |
| Quick duplicate meals & exercises | Yes | Yes |
| AI model pack selection | -- | GLM5.2 Mix / DeepSeek V4 Pro Mix |
| Weekly nutrition report & insights | -- | Yes |
| Priority support | -- | Yes |

New users get a **14-day free trial** of Pro features -- no credit card required.

### Tech stack

- **Frontend**: Vue 3 + Vite + TailwindCSS + ECharts
- **Backend**: FastAPI + SQLAlchemy (async) + PostgreSQL
- **AI**: Multi-provider OpenAI-compatible API
- **Payment**: Creem (Visa, Mastercard, PayPal, Apple Pay, Google Pay)
