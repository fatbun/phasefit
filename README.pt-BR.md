## O que é o PhaseFit?

O PhaseFit é um aplicativo de controle de peso baseado em fases que ajuda você a monitorar nutrição e exercícios com assistência de IA. Em vez de contar calorias manualmente, você pode fotografar suas refeições para obter uma análise nutricional instantânea ou descrever seus treinos em linguagem natural.

### Recursos principais

| Categoria | Grátis | Pro |
|---|---|---|
| Consultas de IA por dia | 5 | 30 |
| Reconhecimento de refeições por foto | Sim | Sim (modelos avançados, maior precisão) |
| Análise nutricional | Básica | Completa |
| Registro de refeições e exercícios | Sim | Sim |
| IA ajustada para a culinária local | Sim | Sim |
| Duplicação rápida de refeições e exercícios | Sim | Sim |
| Faixa de peso saudável | Sim | Sim |
| Seleção de pacote de modelos de IA | -- | GLM5.2 Mix / DeepSeek V4 Pro Mix |
| Relatório nutricional semanal e insights | -- | Sim |
| Suporte prioritário | -- | Sim |

Novos usuários ganham um **teste gratuito de 14 dias** dos recursos Pro -- sem necessidade de cartão de crédito.

### Stack tecnológica

- **Frontend**: Vue 3 + Vite + TailwindCSS + ECharts
- **Backend**: FastAPI + SQLAlchemy (async) + PostgreSQL
- **IA**: API multi-provedor compatível com OpenAI
- **Pagamentos**: Creem (Visa, Mastercard, PayPal, Apple Pay, Google Pay)
