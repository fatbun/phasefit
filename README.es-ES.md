## ¿Qué es PhaseFit?

PhaseFit es una aplicación de gestión de peso por etapas que te ayuda a registrar tu nutrición y ejercicio con asistencia de IA. En lugar de contar calorías manualmente, puedes fotografiar tus comidas para obtener un análisis nutricional al instante o describir tus entrenamientos en lenguaje natural.

### Funciones principales

| Categoría | Gratis | Pro |
|---|---|---|
| Consultas de IA por día | 5 | 30 |
| Reconocimiento de comidas por foto | Sí | Sí (modelos avanzados, mayor precisión) |
| Análisis nutricional | Básico | Completo |
| Registro de comidas y ejercicio | Sí | Sí |
| IA adaptada a la gastronomía local | Sí | Sí |
| Duplicado rápido de comidas y ejercicios | Sí | Sí |
| Rango de peso saludable | Sí | Sí |
| Selección de paquete de modelos de IA | -- | GLM5.2 Mix / DeepSeek V4 Pro Mix |
| Informe nutricional semanal y análisis | -- | Sí |
| Soporte prioritario | -- | Sí |

Los nuevos usuarios disfrutan de una **prueba gratuita de 14 días** de las funciones Pro -- sin necesidad de tarjeta de crédito.

### Stack tecnológico

- **Frontend**: Vue 3 + Vite + TailwindCSS + ECharts
- **Backend**: FastAPI + SQLAlchemy (async) + PostgreSQL
- **IA**: API multi-proveedor compatible con OpenAI
- **Pagos**: Creem (Visa, Mastercard, PayPal, Apple Pay, Google Pay)
