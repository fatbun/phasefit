## PhaseFit とは？

PhaseFit は、AI を活用して栄養と運動を管理するフェーズベースの体重管理アプリです。手動でカロリー計算をする必要はありません。食事を撮影するだけで栄養分析を即座に取得でき、トレーニング内容も自然な日本語で記述するだけで自動的に解析されます。

### 主な機能

| 機能 | Free | Pro |
|---|---|---|
| 1日あたりの AI 利用回数 | 5回 | 30回 |
| 食事写真認識 | 対応 | 対応（高精度モデル） |
| 栄養分析 | 基本 | フル |
| 食事・運動の記録 | 対応 | 対応 |
| 地域の食文化に対応した AI 認識 | 対応 | 対応 |
| 食事・運動のかんたん複製 | 対応 | 対応 |
| AI モデルパックの選択 | -- | GLM5.2 Mix / DeepSeek V4 Pro Mix |
| 週間栄養レポート・分析 | -- | 対応 |
| 優先サポート | -- | 対応 |

新規ユーザーは **14日間の Pro 無料トライアル** をご利用いただけます（クレジットカード不要）。

### 技術スタック

- **フロントエンド**: Vue 3 + Vite + TailwindCSS + ECharts
- **バックエンド**: FastAPI + SQLAlchemy (async) + PostgreSQL
- **AI**: マルチプロバイダ OpenAI 互換 API
- **決済**: Creem（Visa、Mastercard、PayPal、Apple Pay、Google Pay）
